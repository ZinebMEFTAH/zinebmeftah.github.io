# Professional Experience – GE HealthCare

AI & MLOps Engineering Intern (May 2026 – July 2026) at GE HealthCare, Paris. Main project: a production RAG agent letting engineers query complex regulated technical documentation in natural language with cited sources, turning hours of expert lookup into seconds. Built in two phases: first coded end to end in Python (domain-aware preprocessing and chunking, metadata extraction, semantic deduplication, tiered retrieval BM25 → cross-encoder reranker → LLM, prompt caching, query decomposition, MCP integrations to internal requirements-management and wiki systems, orchestrated as modular skills); then re-architected into a multi-agent system on Microsoft Copilot Studio (workflows and specialized subagents) once the linear pipeline's token cost became the bottleneck — the custom preprocessing layer was kept upstream, while retrieval, orchestration and generation moved onto the platform, improving answer quality and processing time at controlled cost. Also shipped autonomous SDLC agents for code review, documentation generation and test automation.
